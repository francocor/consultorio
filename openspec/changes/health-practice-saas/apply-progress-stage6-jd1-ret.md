## Things worth knowing

- **`db:check` can pass vacuously.** When a migration drops and adds columns of one table, `drizzle-kit generate` asks a question and fails without a TTY; `generateInScratch` treats the failure as "no changes". The snapshots of 0685 and 0689 were written by hand and compared with the schema by reading.
- **The `.env.example` test** lists every variable of the main schema. `RELEASER_DATABASE_URL` is read outside that schema on purpose (like the provider variables), so the test stays green until the maintainer adds the line.
- **Stage 6 e2e gate changed.** A billed organization can no longer be cancelled by the operator, so `stage6-demo.spec.ts` leaves through the subscription ("En cancelación") and checks the 409; the export and archive journey is `stage6-archive.spec.ts`.
- **Stack.** `start-stack.ts` runs the releaser as `app_releaser` and brings `afterDays` to 0 after reading a configuration that now refuses 0.
- **Left, documented:** API and worker share `app_rw`; `archive_key.wrapped_private_key` is readable by `app_rw`; governance-mode Object Lock; the id on the erasure command is attribution, not authentication.
