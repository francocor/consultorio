## Design notes

- `subscription_attempt` of kind `cancel` now carries the preapproval it is about in `resource_id` from the mark, so an unknown outcome is settled by reading that one. No schema change.
- A refund token is part of the reference of the refund attempt: the same token is the same refund. No schema change.
- `blocksProvider(row)` separates the parks that make a send unsafe (the three ambiguities) from `reauthorization_needed`.
- The platform cannot pause a preapproval (the port has no method), so the duplicate of an overdue link is caught and given back, not prevented.
