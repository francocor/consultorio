# Stage 3: what each parallel track may touch

The seam slices (S3.00, S3.00b) register every shared piece once. After them a track only **adds files** in its own places and **fills in** the placeholders the seam created for it. This page lists, per track, what it owns and what it must leave alone. If a track needs a change outside its list, that is a new seam commit (ask for it), not an edit made in passing.

The tracks are A messaging (S3.01 to S3.06), B public booking (S3.07 to S3.10), C waitlist (S3.11 to S3.13), D teleconsultation (S3.14, S3.15) and E integration (S3.16 to S3.18). Run order and dependencies are in `tasks.md`.

## Rules for everyone

1. Run `pnpm db:restamp` and `pnpm db:check` after every merge or rebase that touches the journal.
2. Add a locale file for every screen text; no literal text in JSX (lint).
3. A web feature added from Stage 3 on imports another feature only through its `index.ts` (lint).
4. Cross-module calls on the API go through `modules/<other>/index.ts` and through the appointment events.
5. Every mutating route declares `config.audits`, every route a read-only category, every job its queue category.
