# Legacy parity (Stage 2 gate, task 2.101)

The legacy Aillu app lives in its own archived repository (`francocor/AppmedicoCMAillu`); it was never
in production and holds no real data, so there is no migration and no cutover. This repository holds
no legacy code to remove (tasks 2.102 and 2.103 are closed as not applicable). This document maps
each legacy domain, taken from the read-only audit in `openspec/changes/health-practice-saas/exploration.md`,
to the feature that replaces it and to the evidence, so the owner can sign off that Stage 2 covers
what the legacy app did. Facturación and recetas stay reference-only until Stages 4 and 5; the legacy
repository remains the place to recover their screens.

## What was deliberately not ported

The legacy bugs listed in the exploration (the missing comma in `/turnos/vistos`, the undefined `pool`,
the double release of a connection, case-sensitive imports, hardcoded `localhost:4000`) and its design
flaws (public endpoints, client-controlled identity, reset to `1234`, secrets committed, BLOBs in the
database, no tenancy, no audit) are gone by construction; Stage 1 and 2 carry tests for the opposite.

## Beyond parity

Stage 2 also delivers what the legacy app did not have: multi-tenancy with row level security, the
audit trail, versioned and immutable clinical records, the guided first run and solo fast path, the
reception worklist, the document scan pipeline, backups with a restore drill (`docs/runbooks/backup-restore.md`).
